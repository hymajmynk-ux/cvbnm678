# Personal Exam Wallet

محفظة إلكترونية تعليمية تفاعلية تعمل محلياً ببيانات افتراضية فقط.

## المتطلبات
- Node.js 18 أو أحدث
- npm

## التشغيل محلياً
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
npm run preview
```

## تخصيص الإعدادات
عدّل `src/config.js` لتغيير اسم التطبيق، الرصيد الابتدائي، الألوان، الخدمات، والمعاملات الافتراضية. البيانات التي ينشئها المستخدم تحفظ في LocalStorage.

## إعادة ضبط بيانات المتصفح
من تبويب «حسابي» اختر «إعادة ضبط بيانات التجربة»، أو امسح مفتاح `pew_demo_v1` من LocalStorage.

## النشر على GitHub Pages
1. ارفع المشروع إلى مستودع GitHub.
2. شغّل `npm install`.
3. نفّذ `npm run build`.
4. من إعدادات المستودع افتح Pages واختر نشر مجلد `dist` باستخدام GitHub Actions، أو استخدم `npm run deploy` بعد ضبط صلاحيات Pages.
5. لأن Vite مضبوط على `base: './'` فالملفات الثابتة تستخدم مسارات نسبية.

> ملاحظة: التطبيق محاكاة تعليمية مستقلة. لا يتصل ببنك أو محفظة أو مزود دفع، ولا ينفذ أي حركة مالية حقيقية. LocalStorage ليس قاعدة بيانات آمنة؛ لا تستخدم بيانات شخصية أو كلمات مرور حقيقية. كلمة المرور تُحوّل إلى Base64 محلياً في هذا النموذج لتفادي حفظ النص الظاهر مباشرة، لكن ذلك ليس تشفيراً آمناً.


## النشر الصحيح على GitHub Pages (إصلاح الشاشة البيضاء)

1. ارفع **محتويات مجلد** `personal_exam_wallet` إلى جذر المستودع، بحيث يكون `package.json` و`index.html` ظاهرين مباشرة في الصفحة الرئيسية للمستودع. لا ترفع مجلد `personal_exam_wallet` كطبقة داخلية.
2. افتح `Settings` ثم `Pages`.
3. من `Build and deployment` اختر `GitHub Actions` كمصدر النشر.
4. ادفع الملفات إلى فرع `main` أو `master`. ملف `.github/workflows/deploy.yml` سيقوم بتثبيت الحزم وبناء `dist` ونشره تلقائياً.
5. تابع `Actions` حتى تنجح مهمتا Build وDeploy، ثم افتح رابط Pages.

تم إصلاح مسار مدخل JavaScript ليكون نسبياً (`./src/main.jsx`) حتى لا يطلب GitHub Pages الملفات من جذر النطاق. كما أن إعداد Vite يستخدم `base: './'` لدعم روابط المستودعات الفرعية.
